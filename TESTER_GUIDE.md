## 2. Step 1: Create Initial Admin Account (First-Time Only)

Because this is a freshly provisioned database, there are no default passwords stored.

1. Open **[https://sivamsp-lenovo-b490.tail00b6b9.ts.net/admin](https://sivamsp-lenovo-b490.tail00b6b9.ts.net/admin)** in your browser.
2. The **"Create First User"** setup screen will appear.
3. Enter your tester email and a secure password.
4. Click **Create** — you are now logged in as the primary **Super Admin**.

## 3. Testing Checklist & Scenarios

### Test Suite A: Frontend Navigation & Content
- [ ] **Homepage (`/`):**
  - Verify hero headline, CTAs, interactive tabs, customer testimonials, and footer links.
- [ ] **Case Studies (`/case-studies`):**
  - Verify 30 case study cards load with titles, category tags, and summary points.
  - Test category filters (e.g. *Deep Tech*, *Manufacturing Solutions*).
  - Open 3–5 individual case study pages (e.g. `/case-studies/precision-abm-snowflake-cortex`) and verify full rich-text content, challenges, solution steps, and results metrics.
- [ ] **Blogs & News (`/blogs-and-news`):**
  - Verify articles render with publication date, author, key takeaways, and detail views.
- [ ] **Leadership Team:**
  - Verify the About page displays the 5 leadership profiles (CEO, SVP, Directors) with their designations and experience credentials.
- [ ] **Responsive Design:**
  - Test on Mobile (375px), Tablet (768px), and Desktop (1440px). Ensure the mobile slide-out menu opens and navigates smoothly.

---

### Test Suite B: Contact Form & Lead Capture
- [ ] Go to the **Contact Page (`/contact`)**.
- [ ] Fill out the form with test data:
  - *Full Name:* `QA Test Lead`
  - *Work Email:* `qatest@example.com`
  - *Company / Phone / Message:* Enter valid text.
- [ ] Click **Submit Message**.
- [ ] **Expected Result:**
  - Form submits asynchronously without full page reload.
  - Success confirmation message displays clearly.
  - Input fields reset cleanly.

---

### Test Suite C: Admin Panel Verification (`/admin`)
- [ ] **Verify Lead Capture:**
  - In the admin sidebar, open **Contact Submissions**.
  - Verify the submission you made in *Test Suite B* appears with all fields (Name, Email, Message, Submission Time).
- [ ] **Media & Image Uploads:**
  - In the admin sidebar, open **Media**.
  - Click **Create New** and upload any `.png` or `.jpg` image.
  - Save the record.
  - Verify the thumbnail preview appears and responsive dimensions (`400x300`, `800x500`, and `1600x900`) are automatically generated by the backend and served with HTTP 200.
- [ ] **Content Management:**
  - Open **Case Studies** or **Blogs & News**.
  - Edit a headline or description, click **Save**, and refresh the frontend page to verify your update appears immediately.

---

### Test Suite D: Native In-App Analytics
The platform includes its own built-in, GDPR-compliant analytics engine storing telemetry directly in PostgreSQL.

- [ ] Open the browser Developer Tools (`F12`) on the **Network** tab.
- [ ] Browse 2–3 frontend pages.
- [ ] Verify background `POST` requests to `/api/analytics/track` return **HTTP 200 OK**.
- [ ] In the browser, navigate to: `http://100.84.239.20:3000/api/admin/analytics?range=today`
  - Verify it returns aggregated JSON stats (total visitors, page views, top visited URLs, device breakdown).

---

### Test Suite E: RBAC Security & Role Enforcement
In **Admin > Users**, create secondary test users with different roles to verify permissions:

| Role | Marketing Content (Case Studies, Blogs) | Contact Leads (Submissions) | User Management |
| :--- | :--- | :--- | :--- |
| **Super Admin** | Full Access (Create, Edit, Delete) | Full Access | Full Access |
| **Content Editor** | Can Create & Edit | **FORBIDDEN (Hidden)** | Self Only |
| **Lead Manager** | **FORBIDDEN (Hidden)** | Full Access | Self Only |
| **Viewer** | Read-Only (Cannot Edit or Delete) | **FORBIDDEN (Hidden)** | Self Only |

---

## 4. Emergency Password Reset (Server Tool)

If a tester forgets their password or locks an account, run this command from the project root on the server:

```bash
docker compose exec -T app npx tsx scripts/reset_password.ts <user_email> <new_password>
```
